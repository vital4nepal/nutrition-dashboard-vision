# Nutrition Dashboard

Charts and maps of nutrition indicators for Nepal, by province and district. Built with React, Vite, TypeScript and Tailwind.

## Run

```
npm install
npm run dev
```

The dev server opens on port 8080. `npm run build` writes the site to `dist/`.

## Data

`src/assets/nutrition_data_template.csv` shows the columns. `src/assets/sample_nutrition_data.csv` holds sample counts. Both hold aggregate numbers only.
