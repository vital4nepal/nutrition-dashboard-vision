# Nepal Maps

This directory should contain the following map images:

1. `nepal.png` - A map of Nepal showing all provinces
2. `province1.png` - Map of Province 1
3. `province2.png` - Map of Province 2
4. `province3.png` - Map of Bagmati Province
5. `province4.png` - Map of Gandaki Province
6. `province5.png` - Map of Lumbini Province
7. `province6.png` - Map of Karnali Province
7. `province7.png` - Map of Sudurpashchim Province

## Image Sources

You can obtain these maps from:

1. Nepal Government's official websites
2. Nepal's Department of Survey
3. Open source map repositories like OpenStreetMap
4. Geographic information portals for Nepal

## Image Requirements

- Images should be in PNG format with transparent backgrounds if possible
- Recommended resolution: 800x600 pixels or higher
- Each province map should clearly show the boundaries and major cities
- The Nepal map should show all seven provinces with clear boundaries

## Adding the Images

Simply place the image files in this directory with the exact filenames listed above. The application will automatically use these images for the map visualizations.
